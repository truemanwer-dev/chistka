# CHYSTETYKA — multi-page editorial website (v3)

Професійний адаптивний сайт українською мовою для сервісу прибирання квартир у Києві.

## Запуск

Потрібен Node.js 20.19+ (рекомендовано Node 22).

```bash
npm install
npm run dev
```

Відкрийте адресу, яку покаже Vite (зазвичай http://localhost:5173).

Для production: `npm run build` → папка `dist/`.

## Сторінки

- `/` — головна
- `/poslugy` — послуги
- `/pidtrymuvalne-prybyrannia` — підтримувальне прибирання
- `/pidpyska` — підписка
- `/kalkuliator` — триетапний конструктор заявки з інтерактивною схемою квартири
- `/pro-nas` — про компанію, стандарти, команда, хімія
- `/kontakty` — звернення, етапи роботи, FAQ

## Калькулятор

1. Площа, кімнати, санвузли, частота.
2. Додаткові послуги з кількістю кожної.
3. Підсумок і кнопка формування заявки.

У наданому документі **немає фіксованих тарифів**: ціну менеджер називає після короткої розмови. Сайт чесно відображає «Вартість за запитом».

## Заявки

В одному модальному вікні два режими: зворотний дзвінок та Telegram.

- Зворотний дзвінок: до налаштування `VITE_LEAD_ENDPOINT` не відправляється. Після отримання JSON `{ "accepted": true }` від сервера запускається орієнтовний відлік 03:00. Таймер НЕ гарантує дзвінок.
- Telegram: `VITE_TELEGRAM_MANAGER` — username без `@`. Сайт копіює підготовлений текст заявки та відкриває чат для **ручного** надсилання. Без username пропонується лише копіювання; жодного удаваного надсилання.
- Дані зберігаються тільки в стані браузера до підключення бекенду; передавання не відбувається автоматично.

Створіть `.env` на основі `.env.example` тільки після появи каналів зв'язку. Не розміщуйте токен Telegram-бота у frontend або VITE-змінних.

## Особливості дизайну

Editorial Luxury: асиметрія, аркові фото, округлі форми, лінійні декоративні орбіти, великі заголовки, тонкі роздільники; без карткової/кубічної сітки. Фірмові кольори `#1A3E44`, `#C4DADE`, `#FCFCFC`, `#141414`. Шрифти **Onest** і **Golos Text**. Анімації з повагою до `prefers-reduced-motion`.

## Cloudflare Pages

- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`
- `public/_redirects` забезпечує відкриття внутрішніх URL при оновленні сторінки.
